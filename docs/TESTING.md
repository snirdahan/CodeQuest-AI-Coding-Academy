## 3. בדיקות אינטגרציה של התוסף בתוך VS Code אמיתי – `vscode-extension/` (`npm test`)

VS Code **1.143.1** (החבילה הרשמית של Microsoft), עם `@vscode/test-electron`, מול שרת CodeQuest אמיתי. **7 מתוך 7 עברו.**

1. כל הפקודות רשומות.
2. הקישור ש"תרגל ב־VS Code" באתר מייצר מועבר ל־URI handler של התוסף → החשבון מתחבר → קובץ `hello.lua` נוצר רק בתיקיית התרגילים, נפתח בעורך, ופאנל ההוראות מוצג.
3. קוד חיבור לא ניתן לשימוש פעמיים.
4. קוד שגוי → שגיאת ריצה אמיתית, הסבר בעברית, וסימון שגיאה (Diagnostic) בשורה הנכונה בעורך.
5. קוד נכון → עובר, פלט אמיתי, +50 XP, הישג "מפתחים אמיתיים"; **ה־API של האתר מראה מיד 50 XP והשלמה דרך vscode**; בדיקה חוזרת לא נותנת XP נוסף.
6. "לשיעור הבא" פותח את שיעור 2, רמזים מדורגים עובדים, משוב התנהגותי, ו־XP באתר מגיע ל־110.

בנוסף: קובץ ה־VSIX נארז (`vsce package`) והותקן בהצלחה ב־VS Code (`code --install-extension`).

## מה **לא** נבדק עדיין (בכנות)

- פתיחת קישור `vscode://` **דרך מערכת ההפעלה** (לחיצה בדפדפן שפותחת את VS Code). בבדיקה הקישור המדויק מהאתר הועבר ישירות ל־handler של התוסף. את השלב של מערכת ההפעלה צריך לבדוק ידנית על מחשב Windows/Mac.
- Windows ו־Mac בכלל – הכול רץ על Linux.
- עומס של משתמשים רבים במקביל על ה־sandbox.
- נגישות (קורא מסך) – לא נבדק באופן שיטתי.
